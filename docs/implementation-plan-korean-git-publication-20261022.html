2026-10-22 사용자 승인: 현재 PDFCraft에 반영한 한국어 변경을 커밋하고 원격 저장소에 푸시한다. 배포 기준은 main 80b7d21525b263621818427b0223560101d1325f이다. 기존 2,592개 번역 보존, 전체 2,760개 문구, 영어 잔여 47개 보완, 내장 한글 글꼴 연결, 수정판 자산 정책과 Windows 배포 소스를 포함한다. 실행 중인 설치본, 개인 프로필, 기존 소스 작업과 이전 릴리스는 유지한다. 원본 origin에는 읽기 권한만 있어, 사용자가 holyming28-star/pdfcraft 공개 포크 생성을 선택했다. 생성된 포크의 관리자 권한과 main 80b7d215를 확인하고 fork 원격으로 등록했다. main에는 직접 푸시하지 않는다.

개인 프로필·로그·제어 파일·인증서·글꼴 바이너리·빌드 결과·배포 ZIP·로컬 검증 원본은 Git에 추가하지 않는다. 제품 동작 변경이나 재배포는 이 작업에 포함하지 않는다. 일반 CI가 사용하는 선택 글꼴 입력에는 Hang 글꼴이 없으므로, 해당 구성에서는 글리프 검사를 건너뛰되 ko. 배포 라벨에서는 글꼴 누락을 계속 실패로 처리하도록 테스트 조건만 보완한다. 커밋 전 필수 품질 검사는 CLAUDE.md에 따라 범위를 제한해 실행한다.

검증 도구: 원격 main CI run 39768533151은 Rust 1.99.1에서 성공했다. 이 PC의 기존 Rust 1.95.0에서는 원격 main과 동일한 images.rs / compare_ui.rs의 Clippy 경고 때문에 중단되어, 기본 도구 설정은 유지하고 1.99.1을 별도로 설치해 동일한 범위의 검사를 재실행한다. 기존 코드의 경고를 피하려고 제품 동작이나 경고 수준을 바꾸지 않는다. 과거 실패 기록도 로컬 검증 폴더에 보존한다.
